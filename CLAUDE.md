# Проект: сайт кофейни «Тёмный обжар»

Этот файл читает Claude Code при каждом запуске в этой папке.
Здесь записано то, что нужно знать о проекте, чтобы не объяснять заново.

## Что это
Одностраничный сайт кофейни: меню, зерно, мастер-классы, контакты.
Всё в одном файле `index.html`, без сборщиков и фреймворков.
Хостинг: GitHub Pages.

## Форма записи
- Отправляет JSON на адрес из `FORM_ENDPOINT` в `index.html`.
- Приёмник — Google Apps Script (`apps-script/Code.gs`): строка в таблицу + сообщение в Telegram.
- Токен бота хранится только в свойствах скрипта Google. Никогда не вставлять его в код.
- Даты мастер-классов заданы в двух местах: `<select id="f-date">` и `DATES`
  в `index.html`, и `DATES` в `Code.gs`. Менять во всех трёх.

## Правила
- Язык сайта: русский.
- Цвета и шрифты задаются переменными в `:root` в начале `<style>`; новые элементы берут цвета оттуда.
- Сайт должен нормально выглядеть на телефоне (ширина ~375px) и в тёмной теме.
- После правок `Code.gs` напоминать про новое развёртывание в Apps Script.
