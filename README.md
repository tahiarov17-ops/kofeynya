# Сайт кофейни «Тёмный обжар»

Учебный проект: одностраничный сайт с формой записи на мастер-класс.
Заявки попадают в Google Таблицу и приходят сообщением в Telegram.

## Из чего состоит

```
kofeynya-site/
├── index.html          — сам сайт (разметка, стили, скрипт формы)
├── apps-script/
│   └── Code.gs         — приём заявок: таблица + Telegram
├── README.md           — эта инструкция
└── CLAUDE.md           — описание проекта для Claude Code
```

Как идёт заявка:

```
посетитель → форма на сайте → Google Apps Script → Google Таблица
                                                → сообщение в Telegram
```

Почему не напрямую в Telegram из сайта: тогда токен бота лежал бы
в коде страницы, и любой мог бы его украсть. Apps Script прячет токен у себя.

---

## Шаг 1. Создайте Telegram-бота (5 минут)

1. Откройте в Telegram **@BotFather**, отправьте `/newbot`.
2. Придумайте имя и адрес бота (адрес должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AA...`. Это пароль бота:
   никому его не отправляйте и не вставляйте в `index.html`.
4. Найдите своего нового бота и нажмите **Start** (без этого он не сможет вам писать).
5. Узнайте свой **chat_id**: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   (вместо `<ТОКЕН>` — ваш токен). В ответе найдите `"chat":{"id":123456789`.
   Это число и есть chat_id.

## Шаг 2. Подключите приём заявок в Google (10 минут)

1. Создайте новую Google Таблицу, назовите, например, «Записи на МК».
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё в редакторе и вставьте содержимое файла `apps-script/Code.gs`. Сохраните.
4. Слева **⚙ Настройки проекта → Свойства скрипта → Добавить свойство**:
   - `BOT_TOKEN` — токен из шага 1
   - `CHAT_ID` — chat_id из шага 1
5. Проверка: вверху выберите функцию `testTelegram` и нажмите **Выполнить**.
   Google попросит разрешения — разрешите (это ваш собственный скрипт).
   В Telegram должно прийти «Проверка: бот кофейни подключён ✅».
6. **Начать развёртывание → Новое развёртывание**:
   - тип: **Веб-приложение**
   - выполнять от имени: **меня**
   - у кого есть доступ: **все**
7. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

## Шаг 3. Вставьте адрес в сайт

В `index.html` найдите строку

```js
var FORM_ENDPOINT = 'ВСТАВЬТЕ_АДРЕС_APPS_SCRIPT';
```

и вставьте вместо текста в кавычках адрес из шага 2.

## Шаг 4. Выложите сайт на GitHub Pages (10 минут)

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. **New repository** → имя, например, `kofeynya` → **Public** → Create.
3. **Add file → Upload files** → перетащите `index.html` → **Commit changes**.
   (Папку `apps-script` загружать не обязательно, там нет секретов, но сайту она не нужна.)
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
5. Через 1–2 минуты сайт откроется по адресу
   `https://<ваш-логин>.github.io/kofeynya/`.

## Шаг 5. Проверьте

Откройте сайт, запишитесь на мастер-класс. Должны появиться строка
в таблице и сообщение в Telegram.

---

## Если что-то не работает

- **Пишет «Запись пока не подключена»** — не вставлен адрес в `FORM_ENDPOINT` (шаг 3).
- **Пишет «Не получилось отправить заявку»** — проверьте, что в развёртывании
  стоит доступ «все», и что адрес заканчивается на `/exec`.
- **В таблице есть, а в Telegram нет** — проверьте `BOT_TOKEN` и `CHAT_ID`
  и что вы нажали Start у бота. Запустите `testTelegram`.
- **Изменили Code.gs, а ничего не поменялось** — после правок нужно
  **Управление развёртываниями → ✏ → Версия: новая → Развернуть**.
  Адрес при этом останется прежним.

## Свой домен (по желанию)

Купите домен (например, `temny-obzhar.ru`) у любого регистратора и укажите его
в GitHub: **Settings → Pages → Custom domain**. Там же GitHub покажет,
какие DNS-записи добавить у регистратора.
